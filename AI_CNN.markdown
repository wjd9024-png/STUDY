# CNN

## 1-1. FCN 모델
#### 완전 연결층
- 입력을 받아서 출력으로 변환하는 신경망의 기본 모듈

  (입력받은 데이터를 전부 한 줄로 펼치기)
  
  입력 -- Wx(어떤 함수) -- 출력

  각 데이터의 확률이 높은 순서로 출력될 확률이 높다

#### 합성곱 레이어
- 입력 이미지를 필터로 연산 (--> 상수로 나옴)

  (필터는 학습된 무언가)

  입력 이미지 ---- 필터/필터/필터.../필터 ---- 출력
  


#### 필터 시각화
- 선형모델(각 카테고리를 벗어나면 구별 어려움) 

  ---> FCN (다양한 템플렛)
  
  ---> CNN (계층별, 각각 전문적으로 다루는 특징에 집중) 
  
      차이가 미세한 불량(오류)에 대해 압도적 장점 
      ex) 새의 종류 구분

# 강사님 보충 설명

필터를 통과하면 이미지가 줄어든다 + 값도 변환 -----> 효과: 특정 패턴이 강조/무시

ex) 
 사람을 인지
- 머리/ 몸통/ 팔다리  --> 각각 강조되는 패턴이 다르다
  
  ===> 각각을 강조할 수 있는 필터가 필요하다 (채널 - Channel)
  
  ---> 레이어를 통과할 수록 점점 채널이 늘어난다
- 채널은 보통 2의 제곱수를 많이 활용

"일반적으로" 한 레이어를 통과하면
- 채널이 늘어나고
- 각 채널의 이미지 사이즈는 줄어든다.

  --> 연산량과 관련하여 조절해주어야 할 두 가지 옵션
  
  - 스트라이드 (stride)

    : 필터가 몇 칸 이동할까?
    
    스트라이드를 키우면 -> 연산이 줄어들고 / 작은 특징은 무시된다
  - 패딩 (padding)
    
    : 테두리에 여백을 넣어주자

커널 사이즈는 무조건 정사각형만 가능하다 ? --> X

- 범용적으로 정사각형을 쓰기는 하지만
- 특정 패턴을 찾고 싶다면 커널을 가로/세로로 늘려도 됨

    ex) 비행기, 사람


풀링 (Pooling)

- 레이어의 출력결과 해상도를 줄이자!
- 왜 쓸까? 
  
  연산량을 줄이기 위해서
- 많은 정보가 날아갈텐데, 왜 사용가능하지? 
    
        - 위치 정보가 사라지지 않는다.
        - 풀링을 하던 하지 않던 강조될 건 된다!
        - 단, 어느 정도의 정보가 사라지는 맞다.

정규화
- 분산과 표준 편차를 활용해서 데이터를 특정 범위 내로 조정하는 과정

      ex)
      
      -1 -2 -3     ----> 계산 때 다 버려짐
      50 100 200
      1000 2000 4000    ----> 얘만 살아남음
- 각 레이어를 통과하는 값의 분포가 너무 들쭉날쭉하지 않도록 정돈

      ex)

      batech = 1
      --> 한 번에 1개의 이미지만 넣고 학습

      batech = 8
      --> 한 번에 8개의 이미지만 넣고 학습

      -> python, tqdm

레이어를 많이 쌓았다.

-기울기 폭발/소실 문제가 발생

---> 레이어에서 강조/무시 --> 강한건 점점 강조/ 약한건 점점 무시

  ==> 깊은 쪽 층 레이어는 학습이 제대로 안된다. (과적합과 다름)

    과적합

    - 학습 자체는 잘 되었는데, 학습 데이터에 대해서만 잘 학습
    - 새로운 데이터에 대해서는 잘 못한다.

    기울기 소실/ 폭발

    - 애초에 학습 자체가 불안정하거나, 일부 레이어가 학습이 안된다.
